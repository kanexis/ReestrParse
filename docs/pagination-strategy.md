# Стратегия пагинации

## Проблема старого решения

Если для каждой организации открывать карточку в текущей вкладке и затем делать Back,
ЕИАС возвращает список на первую страницу. Для организации с далёкой страницы приходится
снова проходить пагинацию. Сложность фактически приближается к O(N * P).

## Новая стратегия

### Фаза 1 — индексирование

На каждой странице:
1. считать все организации текущей страницы;
2. сохранить ID/URL/название в памяти;
3. нажать Next;
4. дождаться изменения сигнатуры списка;
5. повторить до последней страницы.

Карточки на этом этапе не открываются.

### Фаза 2 — детали

Каждая карточка открывается:
- по прямому URL, если он доступен;
- либо во второй вкладке браузера, сохраняя вкладку списка.

После чтения карточки вкладка закрывается.

Таким образом пагинация проходится ровно один раз.
